# Auto Contact from CC Extension

## Overview

This extension for [iTop](https://www.itophub.io/) automatically creates or links contacts from the CC field in incoming emails. It helps streamline ticket management by ensuring all relevant stakeholders are tracked as contacts.

## Features

- Automatically detects CC recipients in incoming emails.
- Creates new contact records if they do not exist.
- Links existing contacts to the ticket.
- Reduces manual effort in managing contacts.

## Installation

1. Copy the extension folder to `extensions/auto-contact-from-cc/` in your iTop installation.
2. Run the iTop setup to install the extension.
3. Clear the iTop cache.

## Usage

Once installed, the extension works automatically when new tickets are created from emails. CC recipients will be processed and added as contacts.

## Requirements

- iTop 3.1 or higher
